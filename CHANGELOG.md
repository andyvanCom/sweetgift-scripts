# 2026-08-27

## Reliable article product requests

- зависшие read-only RPC-запросы подборок теперь действительно отменяются по
  таймауту, а не продолжают занимать соединение в фоне;
- повторная попытка использует резервный JSON-транспорт, поэтому несколько
  подборок внутри одной статьи не блокируют друг друга.
- таймаут учитывает длительную занятость главного потока скриптами Tilda и не
  отбрасывает уже полученный успешный ответ до выполнения его callback.
- независимые контейнеры статьи снова загружаются параллельно, чтобы нижняя
  подборка не задерживала начало запроса видимой пользователю подборки.
- резервный JSON-запрос запускается через короткую задержку параллельно, а не
  после длинного таймаута; frontend использует первый успешный ответ.
- готовые суточные подборки отдаются через отдельный Edge GET endpoint с
  явной длиной ответа и суточным CDN-кешем; PostgREST остаётся fallback.
- frontend использует выделенный домен `functions.supabase.co`, чтобы запросы
  подборок не делили зависающее соединение с остальными Supabase-модулями.
- два компактных Edge-запроса выполняются последовательно, поскольку один из
  параллельных HTTP/2-потоков Cloudflare мог оставаться незавершённым.
- все 946 активных подборок экспортируются в отдельные статические JSON-файлы
  и отдаются frontend через jsDelivr без запроса к Supabase при открытии;
- GitHub Actions обновляет статический кеш ежедневно после ночного пересчёта.

## Admin authentication and operational state

- вход в SweetGift Admin переведён с постоянного пароля на одноразовый код;
- код отправляется подключённой почтой `no-reply@sweetgift.ru`, а доступ
  разрешён только пользователям с ролью администратора в `app_metadata`;
- ежедневный отчёт считает уникальные товары по стабильному Tilda ID,
  отдельно показывает исторические URL-дубли, размер базы и срок хранения
  подробной аналитики.

## Recommendation safety and article navigation

- товары из специализированных алкогольных разделов централизованно исключены
  из статей, похожих композиций, `/top` и подбора по составу;
- анкоры «Читайте также» теперь используют реальные заголовки целевых статей;
- frontend-загрузка нескольких подборок переведена на надёжные
  последовательные read-only RPC-запросы без зависающего CORS-preflight.

## Архитектура

SweetGift окончательно перешёл от набора JavaScript-скриптов к собственной платформе поверх Tilda.

Основные принципы:

- единый Loader;
- модульная архитектура;
- предварительный расчёт рекомендаций;
- Supabase как основной backend;
- минимальная нагрузка на frontend.

Автоматически определяются:

- SEO-тема;

- повод;
- тип подарка;
- стиль;
- возраст;
- ингредиенты.

Автоматические сущности сохраняются отдельно от ручной разметки.
